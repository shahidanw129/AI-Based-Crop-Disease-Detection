Fieldnote is a student project exploring how image classification, weather information, and structured field observations can support crop-health awareness.

What a model can do

It compares an uploaded image with visual patterns learned from a labelled training dataset. Its output is limited by the quality, balance, and crop coverage of that dataset.

What a model cannot do

A model prediction is not a confirmed diagnosis, does not measure severity, and should not be used alone to choose a treatment. Ask a qualified local agriculture expert before making decisions.

Setup status

Install the optional ML dependencies, organize a labelled dataset, train and evaluate the model, then place its weights and class labels in the documented locations before enabling scans.
